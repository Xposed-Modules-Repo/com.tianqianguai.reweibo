# 功能开关

打开桌面的 **ReWeibo** 应用，或从微博轻享版“我的”页进入 ReWeibo 设置。选择“仅去广告”会打开启动页和信息流去广告，关闭其他布尔开关；微博内设置需要再点击“保存”。关闭微博内入口后，仍可从桌面 ReWeibo 图标进入。

**保存开关后，完全关闭并重新打开微博轻享版生效。** 运行中的进程使用启动时的配置，模块热重载也保留该配置，避免正在执行的缓存任务发生半途切换。已有设置值保留，新增开关默认开启，维持升级前的默认行为。

| 开关 | 控制的行为 |
| --- | --- |
| 我的页 ReWeibo 入口 | 微博“我的”页的设置入口 |
| 移除启动广告 | 启动页广告跳过 |
| 移除信息流广告 | 现有信息流/UVE 广告请求与条目过滤 |
| 过滤无正文内容 | 非广告且没有可显示正文或媒体的空条目过滤 |
| 倒序浏览 | 模块对宿主排序设置、列表布局与数据顺序的干预；关闭后由宿主决定 |
| 扩展缓存 | 模块自动缓存保存、合并、裁剪与恢复 |
| 自动预加载 | 自动请求更多微博；需要扩展缓存 |
| 补齐信息流断层 | 断层探测与回补请求；需要扩展缓存 |
| 阅读位置记忆 | 位置保存、标记与阅读锚点恢复；需要扩展缓存 |
| 双击与时间跳转 | 顶部双击跳到边界、按时间定位；可独立于扩展缓存使用 |
| 补齐正文与媒体 | 正文格式和图片媒体字段修复 |
| 刷新过期视频链接 | 打开视频时替换过期播放地址 |
| 禁用下拉刷新 | 模块阻止下拉刷新的行为；关闭此开关恢复宿主处理 |
| 显示“跳转”按钮 | 时间跳转快捷入口，还需开启“双击与时间跳转” |
| 显示“删除”按钮 | 指定日期缓存清理快捷入口 |
| 持久诊断日志 | 模块详细运行日志写入；关闭不删除已有日志 |

缓存天数继续支持 **1–30 天**。关闭扩展缓存不会删除已有的宿主原生缓存或模块缓存，因此宿主仍可能显示其自身缓存；不会再触发模块的自动恢复与补齐。依赖项的开关选择会保留，重新开启扩展缓存后按原选择运行。手动清理旧缓存、查看或导出已有日志仍可按需使用。

“仅去广告”不修改缓存天数、不清数据，也不修改微博自身已经保存的用户设置。要调整宿主原生排序，请使用微博自身的选项。
