# 日志与性能诊断

开启“持久诊断日志”并重启微博轻享版后，默认记录异常、慢操作、界面生命周期及性能汇总。它不是每个方法都打印一行的调用转储。

## 用户反馈卡顿时

1. 在微博内 ReWeibo 设置进入“运行日志”，点击 **详细诊断 10 分钟**。
2. 按实际使用路径复现，记下卡顿的大致时间、所在页面和操作（例如从特别关注通知进入详情）。
3. 回到日志页点击“停止详细诊断”，按时间范围导出 TXT。十分钟后即使没有手动停止，也自动回到普通记录级别。
4. 如果关闭过持久日志，需要先开启并重启微博；未记录的历史不能补采。进程重启会结束本次详细诊断。

## 能判断什么

| 范围 | 记录 |
| --- | --- |
| 运行环境 | 模块/微博版本、SDK、PID、框架版本、当前功能开关、Hook 安装摘要与失败入口 |
| 页面与输入 | Activity 创建/恢复/暂停、新 Intent 到达、触摸结束操作、首帧、首页内容应用完成 |
| 关联 | session、process、thread、page、op、parent；模块自己的异步任务携带父操作号 |
| 模块阶段 | 缓存合并/裁剪/恢复/写入、排序、过滤、正文修复、跳转、视频刷新、补齐收尾和预加载标记 |
| Hook 耗时 | before_ms、host_ms、after_ms、total_ms，包含完整后置处理和提前返回 |
| 调度 | queue_ms 是超过计划延迟的等待时间，run_ms 是任务执行时间；保留源任务类名 |
| 网络 | probe、source、response/complete/error；observable_age_ms 包含 Observable 创建以来的排队时间，并非纯网络 RTT |
| 卡顿 | 前台主线程心跳超过阈值后的有限堆栈采样及恢复事件 |
| 帧性能 | 五秒窗口的帧数、慢帧数、最长帧耗时、回调丢失数及显示刷新率对应预算 |
| 内存与退出 | 堆占用、系统内存压力回调、可用时读取最近24小时最多5条系统进程退出摘要；未捕获异常记录后仍交给原处理器 |
| 记录器健康 | pending、dropped、write_failures、unconfirmed、written、writer_ms、sampled_out |

`correlation=explicit` 表示线程内或模块异步任务明确传播的操作号；`recent_ui` 仅表示最近十秒的页面/操作上下文，是排查线索，不能单独当作因果证据。首帧事件表示窗口绘制，不等同于网络内容全部加载；`content_applied` 也不等同于后续所有帧完成。

## 开销控制与保留策略

- 日常只记录异常、慢阶段（32ms 起）和必要汇总；相同慢阶段默认最多每秒一条，详细日志也有事件限频。
- 摘要生成前先检查日志级别与频率；列表摘要只读条数及首尾样本，不为打印日志遍历全部微博。
- 写入由专用后台线程批量完成：每250ms最多取128条，队列最多1024条，单条最多4096字符；生产者不获取文件锁、不写盘。
- 队列满会计数丢弃；写盘失败的批次标为 `unconfirmed`，因为部分字节可能已写出，不能冒充成功或确定全部丢失。成功 flush 后才累加 `written`，flush 不代表已强制 fsync 到物理介质。
- 主线程心跳仅前台每秒一次；持续阻塞每两秒最多采样一次、每次阻塞最多三次，每次最多24层堆栈。后台、页面暂停、热重载时停止相应监测。
- 帧回调只累加计数，不逐帧写日志；堆状态每30秒读取一次，正常占用只在详细模式记录，内存压力单独记录。
- 新日志最多为当前文件加三个备份，每段4MiB。首次迁移把旧文件另存为 `.legacy-时间戳`，不删除历史，因此旧档案不计入新日志16MiB上限。
- 预览、筛选和导出包含当前进程的所有轮转段与旧档案；锁内固定文件句柄和长度，扫描期间允许继续追加/轮转。各进程使用不同文件，避免互相轮转；默认界面导出的是当前处理命令的进程日志，并不合并所有辅助进程。
- 不采集 Intent extras、通知正文、请求头或完整 URI；写入前会遮蔽常见凭据字段和 URL 查询部分。分享日志前仍应检查业务标识等个人信息。
- 未捕获异常只等待写线程最多100ms，再委托原异常处理器。进程被强杀、系统掉电或写盘失败时仍可能损失末尾缓冲，不能承诺每次崩溃均有完整堆栈。

## 命令接口

现有 `weico.logs.read/export/status` 保留原语义，读取包含轮转分段。新增：

```text
weico.diagnostics.status   查看级别、会话及队列/丢弃/写失败计数
weico.diagnostics.start    开启十分钟详细诊断
weico.diagnostics.stop     立即结束详细诊断
```

通过现有 `content call --method exec --arg <命令>` 调用，`weico.status` 也附带 diagnostics 状态。导出保持异步操作状态查询方式。

## 验证边界

本地行为测试覆盖日志关闭的短路、队列有界与生产者不等待文件锁、轮转保留、改名后的快照、日期筛选、完整后置计时、跨线程关联及异常处理委托。主机微基准只衡量调用路径开销，不能代替手机上的帧率、耗电或长时间使用测试；不承诺零开销，也不宣称可自动定位宿主与系统的全部卡顿。
