# ReWeibo 1.3.0

新增独立功能开关与“仅去广告”预设，让你自由选择需要的功能。
Adds independent feature switches and an “Ads only” preset so you can choose the features you need.

如果 ReWeibo 对你有帮助，欢迎点一个 Star 支持项目 ⭐
If ReWeibo helps you, please consider leaving a Star to support the project ⭐

## 新增与改进 / Added And Improved

- 新增 16 个功能与入口开关，覆盖启动广告、信息流广告、空内容过滤、排序、扩展缓存、预加载、断层补齐、阅读位置、跳转、正文媒体修复、过期视频刷新、下拉刷新控制、诊断日志及快捷入口。
  Adds 16 feature and entry-point switches covering splash and feed ads, empty-content filtering, ordering, extended caching, preloading, gap filling, reading position, navigation, text/media repair, expired-video refresh, pull-to-refresh control, diagnostic logs, and shortcuts.
- 新增“仅去广告”预设，一次保留启动页与信息流去广告，关闭其他模块功能和入口；不清除已有缓存，不改变缓存天数。
  Adds an “Ads only” preset that keeps splash and feed ad removal while disabling other module features and entry points, without deleting cached data or changing the cache window.
- 新增桌面 ReWeibo 设置入口，微博内设置同步提供完整开关与滚动布局，隐藏微博内入口后仍能重新调整配置。
  Adds a ReWeibo launcher entry and the full switch list in scrollable in-app settings, keeping configuration accessible even when the in-app entry is hidden.
- 功能开关在完全关闭并重新打开微博轻享版后生效，热重载保留当前进程的开关状态；未配置的开关默认保持原有行为。
  Feature switches apply after fully closing and reopening Weibo Lite, and hot reload preserves the current process settings; unset switches retain existing behavior.
- 关闭扩展缓存会暂时停用依赖它的预加载、断层补齐和阅读位置恢复，同时保留用户选择与缓存文件；手动跳转可独立于扩展缓存使用。
  Disabling extended caching suspends dependent preloading, gap filling, and reading-position restoration while retaining saved preferences and files; manual navigation can work independently of extended caching.

## 修复 / Fixes

- 设置页不再在打开时同步扫描整个缓存，缓存清理范围仍通过后台读取，减少大缓存下打开设置的卡顿。
  Settings no longer synchronously scan the entire cache when opened, while cache-clear ranges still load in the background, reducing settings-page stalls with large caches.
- 关闭功能后对应操作恢复宿主处理，关闭去广告时不会再被空内容过滤误删广告条目。
  Disabled features leave their corresponding behavior to the host app, and empty-content filtering no longer removes ad entries when ad removal is disabled.
